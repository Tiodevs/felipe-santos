# Felipe P. dos Santos — AI / LLM Engineer

Página para recrutadores. O visual segue o site da Leemia: tipografia grande, malha, tema claro/escuro e movimento com GSAP. O conteúdo é o Felipe, aberto a vaga CLT ou contrato PJ.

## Stack

Next.js 16, React 19, TypeScript, Tailwind CSS v4, GSAP e Lenis.

## Rodando localmente

```bash
npm install
npm run dev
```

Abre em [http://localhost:3000](http://localhost:3000). O português fica em `/pt` e o inglês em `/en`.

O formulário de contato abre o cliente de e-mail. Não há API nem segredo neste repositório.
